# Conviction Map

Set where you land on eight theological questions and see which church families fit best.

Live at **https://claudekovalenko.github.io/my-theological-convitions/** once GitHub Pages is on.

## Install as an app

- **iPhone / iPad (Safari):** Share button → *Add to Home Screen*.
- **Android (Chrome):** menu → *Install app* (or *Add to Home screen*).
- **Desktop (Chrome / Edge):** the install icon at the right end of the address bar.

It works offline after the first visit. Your answers are saved on the device you use.

## Updating

After you change `index.html`, bump `VERSION` in `sw.js` (for example `v1` → `v2`) so installed copies pick up the change.
